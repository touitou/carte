1) À quoi sert l’outil (rappel simple)

L’outil sert à repérer, comparer et prioriser des opportunités immobilières/foncières.

Il permet de :

  1. filtrer une zone et des critères,
  2. afficher des opportunités sur carte,
  3. ouvrir une fiche détaillée par opportunité,
  4. classer les dossiers selon un score.

2) Sources de données (explication claire)

2.1 Transactions immobilières (DVF)

Ce que c’est : base publique des ventes immobilières.

Ce que ça apporte : date de vente, valeur de transaction, surfaces, repères de prix au m².

Exemple : une parcelle vendue à un niveau inférieur au marché local peut remonter comme opportunité.

2.2 Référentiel bâtiment/parcelle (BDNB)

Ce que c’est : base nationale structurée sur les bâtiments et parcelles.

Ce que ça apporte : géolocalisation, usages, adresse, contexte du bâti.

Exemple : vous visualisez un point sur carte, ou le contour parcelle/bâtiment selon le mode choisi.

2.3 Autorisations d’urbanisme (Sitadel / permis)

Ce que c’est : données sur les demandes et autorisations de projets.

Ce que ça apporte : historique de signaux projet, type/nature de permis, dynamique de transformation.

Exemple : plusieurs permis récents autour d’un site peuvent signaler une zone en évolution.

2.4 Règlementation urbaine (PLU)

Ce que c’est : règles d’urbanisme (zonage, contraintes, documents associés).

Ce que ça apporte : contexte réglementaire de base et pré-qualification des possibilités/contraintes.

Exemple : avant d’engager des études coûteuses, l’équipe vérifie rapidement le cadre de zone.

2.5 Données énergie (DPE)

Ce que c’est : informations de performance énergétique (quand disponibles).

Ce que ça apporte : repérage des actifs à enjeu de rénovation, lecture du potentiel de requalification.

Exemple : un site avec indicateurs énergétiques faibles peut devenir une cible de transformation.

2.6 Données acteurs (propriétaires / entreprises)

Ce que c’est : informations pour identifier propriétaires/acteurs économiques (selon disponibilité).

Ce que ça apporte : meilleure préparation des approches commerciales, compréhension de l’écosystème local.

Exemple : une équipe de prospection prépare ses prises de contact avec une vue plus structurée des acteurs.

3) Écran de recherche — chaque champ expliqué

Astuce : commencez avec des filtres simples, puis affinez en 2e passe.

3.1 Zone et calendrier

Départements

  • Rôle : définit où chercher.
  • Exemple : 93, 94 = opportunités uniquement sur ces départements.

Date min

  • Rôle : borne de départ de l’historique analysé.
  • Exemple : 2024-01-01.

Date max

  • Rôle : borne de fin.
  • Exemple : vide = jusqu’à aujourd’hui.

3.2 Critères économiques principaux

Terrains seulement

  • Rôle : focaliser sur les dossiers avec surface terrain pertinente.
  • Exemple : activé en prospection foncière.

Surface terrain min (m²)

  • Rôle : éliminer les petites emprises.
  • Exemple : 1000.

Prix/m² terrain min

  • Rôle : éviter les valeurs anormalement basses.
  • Exemple : 50.

Prix/m² terrain max

  • Rôle : rester dans votre capacité cible.
  • Exemple : 1500.

Delta vs médiane commune min (€/m²)

  • Rôle : mesure l’écart favorable par rapport au marché local.
  • Exemple : 100.

3.3 Maîtrise du volume

TOP N (limite SQL)

  • Rôle : limite le nombre de dossiers ramenés.
  • Exemple : 300.

Seuil max pour générer la carte

  • Rôle : évite une carte trop lourde.
  • Exemple : 500 = affiner les filtres au-delà.

3.4 Priorisation

Formule score

  • Rôle : personnalise le classement.
  • Exemple : “écart prix × surface”.

3.5 Affichage géographique

Mode géométrie

  • Centroid : point central (rapide).
  • Parcelle : contour parcellaire (qualification).
  • Bâtiment : contour bâtiment (plus fin).

Simplification

  • Rôle : accélère l’affichage.
  • Exemple : 10.

Parcelle principale uniquement

  • Rôle : réduit les doublons.
  • Exemple : activé en phase de tri.

3.6 Enrichissements (cases à cocher)

  • Adresse : lecture terrain plus intuitive.
  • Propriétaires : éléments acteurs utiles pour l’approche.
  • Permis : historique des signaux projet.
  • Urbanisme : contraintes/contextes réglementaires.
  • PLU : zonage réglementaire.

3.7 Scope parcellaire (couverture élargie)

  • Inclure scope parcelles : élargit la couverture.
  • Limiter aux parcelles avec signal permis : garde les cas les plus dynamiques.
  • Inclure scope DVF : renforce via historique transactionnel.
  • Limite max lignes scope parcelles : contrôle le volume.

4) Carte — fiche opportunité champ par champ

Quand vous cliquez un point/contour, une fiche s’ouvre.

4.1 Identification du dossier

  • Transaction : type d’opération (ex. vente).
  • Parcelle : identifiant parcellaire.
  • Cadastre : section + numéro + code commune.
  • Commune : nom de commune.
  • Adresse : affichée quand disponible.
  • Type de bien : terrain / résidentiel / activité…
  • Date mutation : date de transaction.

4.2 Valeur et dimensions

  • Valeur foncière : montant observé.
  • Surface terrain : taille du terrain.
  • Surface parcelle : surface cadastrale.
  • Surface bâti : surface bâtie associée.
  • Ratio bâti/parcelle : indice d’occupation.
  • Visuel bâti : représentation graphique rapide.

4.3 Prix et attractivité

  • Prix/m² terrain : comparaison rapide des dossiers.
  • Médiane commune : référence locale.
  • Écart : différence vs référence locale.
  • Score : priorité calculée.

Exemple : grand terrain + écart favorable + bon score = dossier à qualifier en priorité.

4.4 Caractéristiques du bâti

  • Année construction : idée de l’âge du bâti.
  • Nb niveaux : indication de gabarit.
  • Usage (niveau 1) : grande catégorie d’usage.
  • Usage principal : vocation simplifiée du site.

4.5 Propriétaires et acteurs

  • Propriétaires : liste quand disponible.
  • SIREN valides / autres identifiants : qualification des acteurs.
  • Liens sociétés : compléments d’analyse externes.

4.6 Permis et occupants

  • Historique permis : date, numéro, nature, statut, surfaces.
  • Occupants : aide à comprendre le tissu économique.
  • Demandeurs : acteurs porteurs de projets.

4.7 Énergie

  • DPE logement / tertiaire : classe, consommation, GES.

Exemple : performance faible = potentiel de rénovation/repositionnement.

4.8 Urbanisme / PLU

  • Urbanisme : contexte réglementaire/patrimonial.
  • PLU : zone et liens documentaires.

Important : pré-qualification uniquement ; validation réglementaire finale indispensable.

5) Table de résultats — à quoi elle sert

La table est la vue “pilotage pipeline” : tri par score, comparaison multi-dossiers, extraction d’une short-list.

Méthode type :

  1. trier par score,
  2. vérifier prix/m² et surfaces,
  3. contrôler signaux permis,
  4. produire une liste “Top 20 actions”.

6) Questions métier auxquelles les champs répondent

  • Où ? départements, commune, adresse, carte.
  • Quand ? dates de mutation, historique.
  • Combien ? valeur foncière, surfaces, prix/m².
  • Quel potentiel ? écart local, score, ratio, permis.
  • Quel contexte ? urbanisme, PLU, énergie, acteurs.
  • Que faire ensuite ? prioriser actions commerciales/études.

7) Limites et bon usage

  • L’outil accélère la détection et la priorisation.
  • Il ne remplace pas l’expertise terrain, juridique et urbanistique.
  • Les données peuvent être incomplètes selon les zones/cas.

Conclusion : utilisez l’outil comme un accélérateur de décision, puis confirmez avec les validations métier habituelles.
